## Requirements

[Python](https://www.python.org/) is required, and some packages. Paste the following into command prompt to install them:

`py -m pip install numpy pillow PyOpenGL pyopengltk scipy numba`

You also need a copy of the game. Use [Uwizard](https://digiex.net/threads/uwizard-wii-u-wud-manager-and-nus-downloader.14679/) to extract it into loose files.
